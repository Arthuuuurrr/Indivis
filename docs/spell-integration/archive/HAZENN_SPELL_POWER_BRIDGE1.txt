HAUTE CAPITALE — HAZENNSTUFF -> SPELL POWER BRIDGE1
==================================================

HISTORIQUE — SUPERSEDED.
Ce fichier est conservé uniquement pour traçabilité. Le mapping Arcane large
ci-dessous a été rejeté dans les RC ultérieures.

Objectif
--------
Le port Fabric HazennStuff 1.0.0.b4 conserve ses attributs historiques
hazennstuff:*_spell_power, mais ses sorts d'origine ont été retirés.

Règle de cumul
--------------
Les attributs Hazenn de puissance ont une base 1.0. Le pont convertit chaque
écart à 1.0 en bonus en pourcentage puis additionne les bonus avant de les
appliquer à la puissance Spell Power calculée.

Mapping historique BRIDGE1
---------------------------
Global : hazennstuff:spell_power
Fire : hazennstuff:fire_spell_power
Frost : hazennstuff:ice_spell_power
Lightning/Air : hazennstuff:lightning_spell_power
Water : hazennstuff:hydro_magic_power
Nature : hazennstuff:nature_spell_power
Healing : hazennstuff:holy_spell_power + radiance_spell_power
Blood : hazennstuff:blood_spell_power
Unholy : hazennstuff:shadow_spell_power

ANCIEN MAPPING REJETÉ :
Arcane <- ender_spell_power + cosmic_spell_power + eldritch_spell_power
          + ritual_magic_power + technomancy_magic_power

La lignée finale ne conserve pas cet agrégat Arcane.
