# PRE5 — validation ciblée

- Humain : la jonction 2D -> 3D doit afficher `Barbe taillée`, `Menton noble`, `Barbe ajourée`, jamais `Aucune` pendant qu'une barbe 3D est visible.
- Nordique : tous les noms 3D doivent rester visibles.
- Nain : le bouton `Pilosité` doit être de nouveau visible et cycler toutes les barbes 3D naines.
- Nain : aucune moustache/barbe légère 2D humaine ne doit apparaître.
- `Couleur : Liée aux cheveux` reste fonctionnel.
- `Ornement` n'apparaît que pour une barbe 3D compatible.
- Les trois barbes humaines corrigées doivent rester proches de la tête et ne plus descendre excessivement sur le torse.
