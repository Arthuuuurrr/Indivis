# NexusCharacters Haute Capitale — BETA 1.0 PRE5

PRE5 corrige les trois régressions visibles de PRE4 :

- les noms des barbes 3D sont réappliqués après le rafraîchissement des labels legacy, afin d'éviter `Pilosité : Aucune` lorsqu'une barbe 3D est visible ;
- les Nains sont maintenant reconnus comme ayant accès au système unifié de pilosité, tout en gardant `facialHair=0` pour ne pas leur donner les moustaches/barbes 2D humaines ;
- `Barbe taillée`, `Menton noble` et `Barbe ajourée` ont été raccourcies et resserrées autour de la mâchoire/du menton.

- Minecraft 1.21.11 / Fabric
- version mod : `1.0.0-beta.5+hc.1.21.11`
- aucun changement de schéma réseau
- aucun changement de schéma de persistance
