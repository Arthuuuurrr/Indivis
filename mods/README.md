# Mods

Ce dossier accueillera les **sources** des mods propres au projet.

Chaque mod doit idéalement avoir son propre sous-dossier avec :

- son `README.md` ;
- ses fichiers Gradle ;
- son code source ;
- une note de version/compatibilité Minecraft/Fabric ;
- ses instructions de build ;
- ses dépendances principales.

Exemple :

```
mods/
  capitale-skills/
  capitale-rp-hud/
  nexuscharacters/
  capitale-heraldry/
  capitale-dialogues/
```

Éviter d'utiliser un JAR compilé comme seule source de vérité.
