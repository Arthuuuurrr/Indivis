## French creature names
French display names were added/cleaned for the creature mods embedded in the bundle and for relevant external creature namespaces.
Proper names, taxonomic names and ambiguous invented species names are intentionally preserved when a natural French translation would be uncertain.

Namespaces covered include:
- animalgarden_*
- autonomous_colored_horses
- autonomous_orc_mobs
- chaos_mmo_ai
- cubeanimals
- deermod
- dino_mounts_ai (existing French retained)
- wanderingwildlife
- landsoficaria
- mythika
- myths_of_the_sea
- capitale_entities
- rpg-minibosses generic entity names

Named RPG miniboss characters such as Oyra Ona, Dena Lorenni and Aurelio Voidsinger remain proper names and are not translated.
