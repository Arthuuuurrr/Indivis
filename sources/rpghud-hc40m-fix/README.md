# RPG-HUD HC40M Fix 1.0.1

Corrective rebuild after the invalid hand-built mixin class used in HC40M 1.0.

This project is compiled normally with Fabric Loom 1.13.6 against:
- Minecraft 1.21.11
- Yarn 1.21.11+build.4
- Fabric Loader 0.19.5
- Fabric API 0.141.6+1.21.11

The final replacement RPG-HUD JAR is produced by merging the remapped compiled mixin
and its dedicated mixin configuration into the exact upstream RPG-HUD 3.13 JAR.
