
Commerce EasyNPC — prix suggérés — core 1.5.5
================================================

Objectif
--------
Les achats directs par /trigger ShopChoix sont désactivés côté core.
Le datapack ne distribue plus les objets marchands principaux et n’affiche plus de catalogue joueur pour les boutiques classiques.
Les achats réels doivent être configurés dans l’interface EasyNPC avec l’action Open Trading Menu.

Configuration EasyNPC recommandée
---------------------------------
PNJ marchand simple :
1. Interaction d’entrée : COMMAND executeAsUser=true -> fonction de dialogue du PNJ.
2. Bouton "Ouvrir la boutique" : action Open Trading Menu.
3. Bouton "Discuter" : COMMAND executeAsUser=true -> fonction talk_self du PNJ.
4. Bouton "Partir" : COMMAND executeAsUser=true -> fonction leave_self du PNJ.

Armurier du Port :
- Entrée : function capitale:npc/armurier_port/interact_self
- Discuter : function capitale:npc/armurier_port/talk_self
- Partir : function capitale:npc/armurier_port/leave_self
- Boutique : Open Trading Menu

Libraire agréé :
- Entrée : function capitale:npc/libraire/interact_self
- Discuter : function capitale:npc/libraire/talk_self
- Travail / quête : function capitale:npc/libraire/work_offer_self
- Partir : function capitale:npc/libraire/leave_self
- Boutique : Open Trading Menu
- Cas particulier : ce PNJ garde sa logique de quête « Un exemplaire à remettre ».

Marchand des quais :
- Entrée : function capitale:shop/quais_boissons/menu_self
- Discuter : function capitale:shop/quais_boissons/talk_self
- Partir : function capitale:shop/quais_boissons/leave_self
- Boutique : Open Trading Menu

Prix conseillés
---------------
Comptoir des quais :
- Miche de pain : 1 Martin d’Or
- Poisson grillé : 2 Martins d’Or
- Bière : 2 Martins d’Or
- Whisky : 4 Martins d’Or
- Lot de torches : 1 Martin d’Or

Librairie agréée :
- L’An 682 — Mois du Renouveau : 5 Martins d’Or
- Martins d’Or et franchises : 4 Martins d’Or
- Extrait public des Ordonnances : 5 Martins d’Or
- Archives et Bibliothèque impériale : 5 Martins d’Or
- Notice sur le Cœur et les Profondeurs : 6 Martins d’Or
- Marchés du Cercle et registres du Port : 4 Martins d’Or

Armurier :
- Casque fer : 16 Martins d’Or
- Plastron fer : 48 Martins d’Or
- Jambières fer : 40 Martins d’Or
- Bottes fer : 16 Martins d’Or
- Casque diamant : 75 Martins d’Or
- Plastron diamant : 200 Martins d’Or
- Jambières diamant : 150 Martins d’Or
- Bottes diamant : 75 Martins d’Or

Règles d’équilibrage recommandées
---------------------------------
- Les ressources vanilla farmables ne doivent pas devenir une source directe illimitée de Martins d’Or.
- Les objets de quête, sceaux, preuves, autorisations, titres et reliques ne doivent pas être vendus librement.
- Les livres publics peuvent être vendus ; les textes restreints doivent plutôt dépendre d’une quête, réputation, autorisation ou exploration.
- Les armures vendues librement doivent rester non enchantées ou faiblement configurées.
- Les achats importants doivent rester plus liés aux quêtes, réputations, droits et métiers qu’au farm pur.

Limite technique
----------------
Le datapack ne peut pas ouvrir le Default Trading Menu EasyNPC sans commande dédiée exposée par EasyNPC. Les fonctions de fallback affichent seulement un rappel admin. L’ouverture réelle doit être configurée dans EasyNPC.
