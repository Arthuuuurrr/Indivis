GUIDE — Vendeurs diversifiés EasyNPC
Version core : 1.5.5 hotfix more_vendor_dialogues_native

PRINCIPE
- Le dialogue reste natif EasyNPC.
- Le bouton "Ouvrir la boutique" doit être l’action EasyNPC Open Trading Menu.
- Les fonctions datapack servent aux boutons "Discuter", "Partir" et aux salutations de secours.
- Les trades doivent être créés avec les vrais items pris dans l’inventaire, pas avec des composants copiés à la main.

CONFIGURATION TYPE
Dialogue EasyNPC :
- Texte d’entrée RP adapté au métier.
- Ouvrir la boutique -> Open Trading Menu.
- Discuter -> COMMAND executeAsUser=true -> function capitale:npc/<vendeur>/talk_self.
- Partir -> COMMAND executeAsUser=true -> function capitale:npc/<vendeur>/leave_self, ou Close Dialog.

AGRICULTEUR
Fonctions :
- function capitale:npc/agriculteur/interact_self
- function capitale:npc/agriculteur/talk_self
- function capitale:npc/agriculteur/leave_self
Dialogue conseillé :
"Les étals sont simples, mais les greniers tiennent la ville debout."
Prix conseillés :
- Blé x16 : 1 Martin.
- Carottes ou pommes de terre x16 : 1 Martin.
- Betteraves x16 : 1 Martin.
- Bottes de foin x2 : 2 à 3 Martins.
- Pommes x4 : 2 Martins.
- Graines x16 : 1 Martin.

MARCHAND D'ARTEFACTS CAPSKILLS
Fonctions :
- function capitale:npc/marchand d'artefacts_capskills/interact_self
- function capitale:npc/marchand d'artefacts_capskills/talk_self
- function capitale:npc/marchand d'artefacts_capskills/leave_self
Dialogue conseillé :
"Je ne vends pas la maîtrise. Je remplace seulement les outils de ceux qui l’ont déjà méritée."
But : vendeur de remplacement si un joueur perd un item CapSkills.
Important : acheter l’objet ne devrait pas donner la compétence. Les fonctions CapSkills doivent continuer à vérifier les tags/skills du joueur.
Items à placer dans les trades depuis l’inventaire :
- /function capskills:give/mod/baguette_soins_self
- /function capskills:give/mod/relais_rempart_self
- /function capskills:give/mod/baguette_alteration_self
- /function capskills:give/mod/baguette_destruction_self
Prix conseillés :
- Sceau / baguette de soins : 24 Martins.
- Relais du Rempart : 28 Martins.
- Baguette / alambic d’altération : 32 Martins.
- Focus / baguette de destruction : 36 Martins.
- Set complet de remplacement : éviter en vente groupée libre, ou 100+ Martins.

À ÉVITER
- Ne pas faire racheter les ressources farmables à prix fixe infini contre des Martins d’Or.
- Ne pas vendre les objets de quête majeurs sans score/réputation associé.
- Ne pas transformer le marchand d'artefacts en source de progression : il doit remplacer les outils, pas vendre les compétences.
- Ne pas garder un trade qui provoque "Sanitized 1 invalid trade(s)".
