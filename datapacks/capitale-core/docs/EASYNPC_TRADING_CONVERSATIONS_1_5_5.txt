Capitale Core 1.5.5 — EasyNPC Trading Conversations Only

Objectif
- Le datapack ne doit plus afficher de catalogue joueur pour les boutiques classiques.
- Le joueur voit les objets/prix dans le Default Trading Menu EasyNPC.
- Le datapack fournit seulement les répliques RP et les fonctions de fallback.

Configuration recommandée dans EasyNPC

1) Armurier du Port
Interaction principale :
  COMMAND executeAsUser=true : function capitale:npc/armurier_port/interact_self

Boutons EasyNPC conseillés :
  Ouvrir la boutique -> Open Trading Menu
  Discuter -> COMMAND executeAsUser=true : function capitale:npc/armurier_port/talk_self
  Partir -> COMMAND executeAsUser=true : function capitale:npc/armurier_port/leave_self

Fallback chat existant :
  /trigger ShopChoix set 280 -> rappel Open Trading Menu
  /trigger ShopChoix set 281 -> discuter
  /trigger ShopChoix set 282 -> partir

2) Marchand des quais
Interaction principale :
  COMMAND executeAsUser=true : function capitale:shop/quais_boissons/menu_self

Boutons EasyNPC conseillés :
  Ouvrir la boutique -> Open Trading Menu
  Discuter -> COMMAND executeAsUser=true : function capitale:shop/quais_boissons/talk_self
  Partir -> COMMAND executeAsUser=true : function capitale:shop/quais_boissons/leave_self

Fallback chat existant :
  /trigger ShopChoix set 80 -> rappel Open Trading Menu
  /trigger ShopChoix set 82 -> discuter
  /trigger ShopChoix set 81 -> partir

3) Libraire agréé
Cas particulier : PNJ marchand + quête Divers « Un exemplaire à remettre ».
Ne pas le traiter comme un vendeur classique pur.

Interaction principale :
  COMMAND executeAsUser=true : function capitale:npc/libraire/interact_self

Boutons EasyNPC conseillés :
  Ouvrir la boutique -> Open Trading Menu
  Parler des livres -> COMMAND executeAsUser=true : function capitale:npc/libraire/talk_self
  Vous auriez du travail pour moi ? -> COMMAND executeAsUser=true : function capitale:npc/libraire/work_offer_self
  Partir -> COMMAND executeAsUser=true : function capitale:npc/libraire/leave_self

Fallback dialogue existant :
  /trigger QuestChoix set 120 -> rappel Open Trading Menu
  /trigger QuestChoix set 123 -> parler des livres
  /trigger QuestChoix set 121 -> quête/travail
  /trigger QuestChoix set 122 -> partir

Prix suggérés pour config EasyNPC

Comptoir des quais
- Pain : 1 Martin d’Or
- Poisson grillé : 2 Martins d’Or
- Bière : 2 Martins d’Or
- Whisky : 4 Martins d’Or
- Torches simples : 1 Martin d’Or le petit lot

Librairie publique
- Livres publics simples : 4 Martins d’Or
- Livres publics utiles / lore central : 5 Martins d’Or
- Livres publics plus spécialisés : 6 Martins d’Or
- Textes restreints / interdits : ne pas vendre librement ; quête, accès, réputation ou exploration.

Armurier
- Casque fer : 16 Martins d’Or
- Plastron fer : 48 Martins d’Or
- Jambières fer : 40 Martins d’Or
- Bottes fer : 16 Martins d’Or
- Fer complet : 120 Martins d’Or
- Casque diamant : 75 Martins d’Or
- Plastron diamant : 200 Martins d’Or
- Jambières diamant : 150 Martins d’Or
- Bottes diamant : 75 Martins d’Or
- Diamant complet : 500 Martins d’Or
- Armures enchantées fortes : éviter la vente libre.

Remarque
Le datapack ne peut pas ouvrir le Default Trading Menu EasyNPC en commande vanilla sans commande dédiée exposée par EasyNPC. Les entrées “Ouvrir la boutique” en fallback chat affichent seulement un rappel. L’ouverture réelle doit être configurée dans le bouton EasyNPC.
