Guide EasyNPC — Near Distance des PNJ commerçants — Capitale 1.5.6 RC9g

Objectif
- Ajouter des répliques de proximité aux marchands sans ouvrir la boutique.
- La boutique reste un bouton natif EasyNPC "Open Trading Menu" dans le dialogue principal.
- Les near distances appellent seulement une fonction de dialogue court.

Réglage EasyNPC recommandé
- Near Distance / Proximity action : COMMAND
- executeAsUser : true
- permissionLevel : 2 si nécessaire
- distance conseillée : 4 à 6 blocs pour les étals serrés, 6 à 8 blocs pour les places ouvertes.
- éviter d'activer Near Distance sur trop de PNJ décoratifs inutiles.

Cooldown
- Toutes les fonctions near utilisent NPC_NEAR_CD.
- Durée : 120 ticks, soit environ 6 secondes.
- Le cooldown est partagé par joueur afin d'éviter les cascades de messages dans un marché dense.

Fonctions à utiliser
Brasseur du Port:
function capitale:npc/brasseur_port/near_self
Alias historique possible:
function capitale:shop/quais_boissons/near_self

Armurier:
function capitale:npc/armurier_port/near_self

Libraire agréé:
function capitale:npc/libraire/near_self

Agriculteur:
function capitale:npc/agriculteur/near_self

Boucher:
function capitale:npc/boucher/near_self

Marchand d'artefacts:
function capitale:npc/artefactier_capskills/near_self

Apothicaire:
function capitale:npc/apothicaire/near_self

Quincaillier:
function capitale:npc/quincaillier/near_self

Cartographe:
function capitale:npc/cartographe/near_self

Important
- Le bouton "Ouvrir la boutique" doit rester une action EasyNPC native Open Trading Menu.
- Les fonctions near ne vendent rien et ne lancent pas le trading menu.
- Le libraire conserve une logique plus riche car il peut être lié à une quête.
