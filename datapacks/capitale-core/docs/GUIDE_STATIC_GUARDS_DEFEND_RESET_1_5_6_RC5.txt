GUIDE — GARDES STATIQUES DEFEND SELF / RETOUR AU POSTE — 1.5.6 RC5

Objectif
- Permettre aux gardes statiques non-accès de se défendre et poursuivre un joueur.
- Les ramener automatiquement à leur poste après 30 secondes.
- Éviter de régler manuellement une position dans chaque PNJ.

Configuration EasyNPC recommandée
1. Dans le preset des gardes statiques concernés : activer Defend Self.
2. Conserver l'action pénale joueur :
   executeAsUser=true
   function capitale:npc/<famille>/static_port/on_hurt_self
3. Ajouter l'action PNJ de timer retour :
   executeAsUser=false
   function capitale:npc/static_guards/defend_reset/on_hurt_npc_self

Ancrage admin sans ouvrir chaque PNJ
- Se placer près du garde statique concerné.
- Lancer :
  /function capitale:admin/static_guards/menu_self
- Utiliser :
  [Tag + ancrer PNJ proche]

Bulk
- Si plusieurs PNJ déjà tagués cap_static_guard_resettable sont chargés :
  /function capitale:npc/static_guards/defend_reset/setup_loaded_tagged

Reset manuel
- Pour ramener immédiatement les gardes actifs :
  /function capitale:npc/static_guards/defend_reset/reset_all

Notes
- Le système utilise des markers invisibles d'ancrage.
- Le marker est lié au PNJ par CAP_STATIC_GUARD_ID.
- Le tick ne traite que les PNJ ayant le tag cap_static_guard_active.
- Ne pas appliquer aux gardes d'accès sensibles si leur position ne doit jamais bouger.
