Haute Capitale Core 1.5.6 RC1 — Invisibilité et gardes

Principe:
- Les joueurs avec l’effet minecraft:invisibility ne déclenchent plus les détections passives ordinaires des gardes.
- Cela concerne les contrôles d’accès static/patrol appelés par EasyNPC near-distance.
- Un joueur recherché peut donc utiliser l’invisibilité pour fuir une détection passive.
- Exception retenue: si le joueur est sous minecraft:glowing, il redevient détectable.

Ce qui n’est pas contourné:
- attaques de gardes;
- crimes déclenchés explicitement;
- dialogues volontaires;
- PNJ de quête/vendeurs;
- fonctions admin.

Tests:
/function capitale:debug/stealth/status_self
/effect give @s minecraft:invisibility 60 0 true
/effect give @s minecraft:glowing 60 0 true

Implémentation:
- data/capitale/predicate/player/is_invisible.json
- data/capitale/predicate/player/is_glowing.json
- data/capitale/predicate/player/hidden_from_ordinary_guards.json
- 54 fonctions access/static et access/patrol filtrent maintenant l’eval passive avec:
  execute unless score @s CAP_ACCESS_CD matches 1.. unless predicate capitale:player/hidden_from_ordinary_guards run function ..._eval_self
