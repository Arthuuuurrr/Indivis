Capitale Core 1.5.5 STABLE — notes de version

Base : capitale_core_beta_1_5_5_rc3_patrol_uuid_habillage_presets.

Alignements appliqués :
- pack.mcmeta et menus mis à jour vers 1.5.5 stable ;
- menu CapSkills aligné sur CapSkills 0.8.29e et capitale_skills_items 1.1.6 advanced-hooks ;
- menu monnaie aligné sur capitale_currency 0.1.6 ;
- fonction de test stable /function capitale:admin/test/socle155_self ajoutée ;
- anciens chemins alpha154_self et alpha155_self conservés comme wrappers de compatibilité ;
- documentation historique consolidée dans docs/archive/HISTORIQUE_CORE_AVANT_1_5_5_STABLE.txt.

Décision importante sur la monnaie :
- le core ne doit pas ajouter custom_name/lore aux Martins d’Or ;
- toutes les sorties monnaie doivent rester sur l’item brut capitale_currency:martin_dor ;
- le rendu gold/gras/lore est porté par le mod currency 0.1.6 ;
- cela préserve la stackabilité avec /give @s capitale_currency:martin_dor et limite les risques de trades EasyNPC divergents.

Décision importante sur les fonctions :
- aucune fonction gameplay/EasyNPC n’a été supprimée automatiquement ;
- beaucoup de fonctions non référencées par d’autres functions sont des points d’entrée EasyNPC, admin ou test manuel ;
- les suppressions agressives sont donc reportées à un audit en jeu avec liste d’UUID/PNJ.
